# pkg

В данной директории размещаются файлы, которые можно импортировать в других приложениях. 

Например, сюда можно поместить:
- сгенерированные контракты из proto-файлов
- публичные библиотеки и утилиты
- общие модели данных
- клиентские SDK

В `proto/shortener/v1` лежит сгенерированный контракт gRPC-сервиса. Руками его править не нужно: правится `api/proto/shortener/v1/shortener.proto`, затем выполняется `make proto`.
