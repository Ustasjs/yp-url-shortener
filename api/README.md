# api

В этой директории принято размещать proto-файлы или файлы в формате OpenAPI/Swagger для описания контракта сервиса.

Контракт gRPC-сервиса лежит в `proto/shortener/v1/shortener.proto`. Это источник правды: после его правки нужно выполнить `make proto`, чтобы обновить сгенерированный код в `pkg/proto/shortener/v1`.
